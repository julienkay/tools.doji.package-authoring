# UPM Package Authoring

Full documentation: https://docs.doji-tech.com/tools.doji.package-authoring/

## Overview

Editor tooling that generates a new UPM package repository: the package itself, a companion Unity project, and supporting files (README, LICENSE, AGENTS.md, DocFX docs, CI workflow).

## Requirements

Unity 6000.0 or newer. Editor only; nothing is included in player builds.

## Usage

- `Window > Package Authoring > Create Package...` opens the wizard that generates a package repository with a companion project.
- `Window > Package Authoring > Create Project...` generates a standalone Unity project.
- `Project Settings > Doji > Package Authoring` holds per-project defaults and editable templates for the generated files.
